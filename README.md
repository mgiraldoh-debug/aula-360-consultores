# Aula 360 Consultores – Entrenamiento Docente

Aula 360 Consultores es un proyecto de formación y acompañamiento para la comunidad educativa. Su propósito es apoyar el desarrollo profesional docente mediante recursos educativos, capacitaciones, talleres y asesorías.

> **Estado del proyecto:** la página web institucional está publicada. Actualmente ofrece recursos descargables y reservas de asesorías. Los cursos y talleres todavía no se realizan directamente desde la web; esa capacidad está planificada, no implementada.

## ¿A quién está dirigido?

Principalmente a docentes de distintas áreas del conocimiento y, según el servicio, a directivos y otros integrantes de la comunidad educativa. La visión es alcanzar a educadores de Panamá y de otros países de Latinoamérica.

## ¿Qué ofrece actualmente?

Según la información proporcionada por la responsable del proyecto:

- Página web institucional: https://giraldomilena.wixsite.com/website
- Recursos educativos descargables.
- Reservas de asesorías.
- Experiencia previa impartiendo capacitaciones y entregando certificados.

Entre los temas de capacitación ya trabajados se encuentran:

- Estrategias docentes.
- Manejo del aula.
- Disciplina asertiva.

## Visión de crecimiento

Se contempla desarrollar una plataforma digital que pueda incluir:

- Cuentas personales para docentes.
- Cursos y talleres virtuales.
- Materiales educativos organizados por área o tema.
- Evaluaciones y seguimiento del aprendizaje.
- Certificados digitales, de acuerdo con los requisitos de cada formación.
- Recursos gratuitos, cursos individuales de pago, membresías y asesorías.

Estos elementos son **propuestas futuras**. No deben describirse como funcionalidades disponibles hasta que se desarrollen y verifiquen.

## Estado: hecho y pendiente

- Sitio web institucional.

- Reservas de asesorías.

- Gestión de inscripciones y pagos.
- Evaluaciones y seguimiento de cursos.

- Herramienta tecnológica definitiva y presupuesto de operación.

## ¿Cómo empezar?

1. Lee este README para conocer el propósito y el estado del proyecto.
2. Consulta [CONTRIBUTING.md](CONTRIBUTING.md) antes de proponer cambios.
3. Revisa los Issues abiertos para encontrar tareas pequeñas.
4. Si tienes una propuesta, abre un Issue antes de realizar cambios.
5. Envía tus aportes mediante un Pull Request para que puedan revisarse.

## Primera tarea sugerida

Documentar y verificar el recorrido actual de una persona que visita la web y reserva una asesoría. Consulta el Issue de ejemplo incluido en `docs/issue-inicial.md`.
